Technical Architecture, Rigor, Limitations & Roadmap

Defensible Engineering Choices, Explicit Bias Handling, and Strategic Vision

⚙️ Full-Stack Execution
  • Vertex AI & Gemini 2.5 Flash: Orchestrated via Google ADK runtime with 7 custom Python domain tools under 600ms latency.
  • BigQuery ML ML.EXPLAIN_PREDICT: Unpacks microclimate drivers per block: canopy deficit (+2.4°F), asphalt density (+1.8°F), pre-1970 housing vintage.
  • Production Cloud Run: Serverless Python agent hosting /run endpoint with structured JSON traces.
  • Executive GIS Dashboard: React 18 + TypeScript + Leaflet with real-time baseline heat slider (85°–105°F) & 800m isochrones.
🛡️ Rigor & Decisions Defended
  • Proactive Bias Handling: Race and ethnicity were strictly excluded from model features to prevent algorithmic redlining proxies.
  • Outcome Equity Audit: Rather than assuming fair intent, the agent programmatically validates sites against citywide 75th-percentile hardship thresholds.
  • Offset vs. Raw Temp: Raw temps overfit seasonal shifts; microclimate thermal deltas isolate permanent physical infrastructure effects.
  • Data Schema Validation: Audited NOAA GHCN & CDC SVI joins for zero-null integrity across all 109 Atlanta tracts.
🔍 Honest Limitations & Next Steps
  • Single-Day Traverse Baseline: NOAA Heat Watch data is captured on one representative hot day; extreme weather variances require longitudinal expansion.
  • No Counterfactual Tree Simulation: ML.EXPLAIN_PREDICT diagnoses *why* a tract is hot, but cannot simulate post-planting cooling without multi-year canopy growth data.
  • ⚡ Today: Dispatch mobile hydration vans & cooling buses during Heat Advisories (≥95°F).
  • 🏛️ This Budget Cycle: Fund solar-reflective shade-sails at 42 unshaded MARTA stops inside the 10-minute walk buffers.
  • 🌳 This Decade: Urban reforestation program focused on bottom 20% canopy tracts.
